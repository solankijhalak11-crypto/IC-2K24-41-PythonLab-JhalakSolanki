## Assignment Overview
This assignment studies how different methods can solve the same problem with different amounts of time and memory.

## Files
- `Section_A.txt` – Initial questions and answers.
- `Section_B.ipynb` – Sum of prime numbers using a basic method, square-root checking and the Sieve of Eratosthenes.
- `Section_C.ipynb` – Count pairs with a target sum using nested loops and a dictionary.
- `Section_D.ipynb` – Find the K-th smallest pairwise sum using a basic approach and a faster approach with sorting, two pointers and binary search.
- `Section_E.ipynb` – Final reflection.

## How to Open
Open the notebook files in Jupyter Notebook, JupyterLab, or Google Colab. Run the code cells in order.
