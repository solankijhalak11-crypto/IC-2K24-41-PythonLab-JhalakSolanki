## Programs

This lab contains six basic Python programs:

1. **Variable Types** – Creates variables and displays their data types using `type()`.
2. **Introduction Program** – Takes name, age and city as input and displays them using an f-string.
3. **Basic Calculations** – Performs addition, subtraction, multiplication, division and remainder.
4. **Celsius Converter** – Converts temperature from Celsius to Fahrenheit.
5. **String Methods** – Uses `upper()`, `lower()`, `strip()` and `len()`.
6. **Food Receipt** – Prints a sample food bill using tab spacing.

## How to Run

Open the folder in Visual Studio Code or a terminal.

Run any program with:

```bash
python filename.py
```

For example:

```bash
python intro_program.py
```
