
# Python Dictionary – Lab 5, Part A

## Overview
This folder contains five Python programs based on dictionaries and nested dictionaries. The programs use simple functions and menu-based options to manage sample records and display reports.

## Programs

### Q1. Student Database — `Student_Marks_Manager.py`
- Add, update, delete and search student records.
- Store marks for different subjects.
- Check marks within the range of 0 to 100.
- Display averages, topper, subject toppers, low marks and grade groups.

### Q2. Employee Database — `Staff_Salary_Manager.py`
- Add, update, delete and search employee details.
- Calculate department payroll and employee count.
- Find the highest-paid employee in each department.
- Sort employees by salary.
- Prepare a separate dictionary showing a 10% raise for salaries below ₹50,000.
- Find the department with the highest average salary.

### Q3. Library Record System — `Book_Issue_Return_System.py`
- Add books and increase the number of copies.
- Issue and return books.
- Allow a member to hold up to two books.
- Search book records and display library reports.

### Q4. Word Frequency Counter — `Paragraph_Word_Analyzer.py`
- Read a paragraph and remove punctuation.
- Count each word using a dictionary.
- Display the top N words.
- Find words used once, reverse the frequency dictionary and group words by length.
- Search for a word.

### Q5. Phone Directory — `Contact_Book_Manager.py`
- Add, update, search and delete contacts.
- Store more than one phone number for a contact.
- Check phone numbers for exactly 10 digits and avoid duplicates.
- Search by part of a name or by phone number.
- Group contacts by city and display the directory alphabetically.

## Concepts Used
- Dictionaries and nested dictionaries
- Lists as dictionary values
- Functions, loops and conditions
- Dictionary methods such as `get()`
- Dictionary comprehensions
- Sorting, grouping and aggregation
- Input validation

## How to Run
1. Open this folder in VS Code.
2. Open the terminal.
3. Run one program at a time, for example:

```bash
python Student_Marks_Manager.py
```

Replace the filename with the program you want to run.

## Note
The programs use sample records to demonstrate the required operations. Run each program and try different inputs to understand how the dictionary data changes.
