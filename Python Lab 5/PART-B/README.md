# Python Dictionary – Lab 5, Part B

## Overview
This part contains eight output-prediction questions based on Python dictionaries. Each question includes a short code example, its output or result, and an explanation.

## Topics Covered
1. Dictionary aliasing
2. Shallow copying
3. Dictionary comprehension with a condition
4. The `setdefault()` method
5. Equivalent dictionary keys
6. Removing dictionary items during iteration
7. The `pop()` and `popitem()` methods
8. Duplicate keys created by dictionary comprehension

## Files
- `Dictionary_Output_Practice.txt` – all eight questions, code snippets, outputs and explanations.

## How to Practise
1. Read each code snippet and predict its output.
2. Write down your prediction before running the code.
3. Run the snippet in Python 3.
4. Compare the actual output with the answer.
5. Review the explanation for any answer that was different.

## How to Run
Copy an individual code snippet from `Dictionary_Output_Practice.txt` into a Python file or Python editor and run it.
