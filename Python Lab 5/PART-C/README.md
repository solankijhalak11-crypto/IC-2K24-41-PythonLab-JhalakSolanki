# Python Dictionary – Lab 5, Part C

## Overview
Part C contains eight short reasoning questions with answers about Python dictionaries. It is intended to help revise important dictionary concepts and understand how they work in practical programs.

## Topics Covered
- Assignment, shallow copy and deep copy
- Hashable and unhashable keys
- Dictionary access using `[]` and `.get()`
- Updating dictionary values with assignment and `.update()`
- Dictionary comprehensions
- Safe deletion while iterating
- Reversing book-to-member records
- Dictionary and list lookup time complexity

## Files
- `Dictionary_Concept_Review.txt` – all eight questions, answers and code examples.

## How to Use
1. Read each question.
2. Try to explain the answer in your own words.
3. Review the example code.
4. Practise the snippets in Python 3.

## Requirements
- Python 3.x
- VS Code or any Python editor
