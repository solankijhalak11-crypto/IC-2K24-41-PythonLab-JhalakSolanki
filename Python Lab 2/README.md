## Programs

This lab contains six programs based on star and number patterns.

1. **Centered Star Triangle** (`centered_star_triangle.py`)  
   Takes the number of rows and prints a centered triangle of stars.

2. **Star Square** (`star_square.py`)  
   Takes the size and prints a square made of stars.

3. **Left Star Triangle** (`left_star_triangle.py`)  
   Prints a right-angle triangle with one extra star in each row.

4. **Inverted Star Triangle** (`inverted_star_triangle.py`)  
   Prints a triangle that starts with the maximum number of stars and decreases row by row.

5. **Rhombus Stars** (`rhombus_stars.py`)  
   Prints a rhombus pattern using spaces and stars.

6. **Symmetric Number Pattern** (`symmetric_number_pattern.py`)  
   Uses nested `for` loops to print a number pattern that decreases toward the middle and then increases.

## How to Run

1. Open this folder in Visual Studio Code or a terminal.
2. Run a program with the command below:

   ```bash
   python filename.py
   ```

3. Enter the value requested by the program.
